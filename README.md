# Rhode Community

**Creator:** Sarah Safwan  
**Project type:** Independent speculative brand strategy and interactive website concept.

A proposed customer-centered community experience for Rhode, exploring customer engagement, product co-creation, and digital experiences.

## Features

- Community homepage and feature navigation
- Simulated membership access without real accounts or purchase verification
- Hypothetical founder Q&A with local question submissions and voting
- Discussions, replies, search, and category filters
- Product ideas, voting, and illustrative development stages
- Simulated testing applications
- Proposed rewards and membership benefits
- Conceptual international experiences and demonstration RSVPs
- Your Impact journey and local contribution tracking

## Technology

Static HTML, CSS, and vanilla JavaScript. Hash-based navigation and browser `localStorage` support the demonstration. Optional Google Fonts provide DM Sans and Manrope, with local font fallbacks. No framework, build step, backend, database, payment system, or real authentication is used.

## Local development

From the repository root:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/. Keep `index.html`, `styles.css`, `app.js`, and `assets/` together. Reset saved activity using the footer control.

## GitHub Pages deployment

The site is prepared for branch-based GitHub Pages publishing from `main`, directory `/ (root)`. Select those settings under **Settings → Pages → Deploy from a branch** after uploading the files. `.nojekyll` keeps the static files unchanged. Relative asset paths and hash navigation support the `/rhode-community/` project path.

Deployment is pending; a live prototype link will be added after the public site is verified.
